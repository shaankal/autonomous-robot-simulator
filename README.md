# Autonomous Robot Learning Simulator

A robotics and reinforcement learning project exploring
autonomous navigation in simulated environments.

## Project Goals

- Build a custom 2D warehouse navigation simulator.
- Implement classical pathfinding algorithms.
- Train reinforcement learning agents using PPO.
- Benchmark navigation performance on unseen environments.
- Extend the simulator with MuJoCo physics.

## Tech Stack

Python, PyTorch, Gymnasium, Stable-Baselines3,
Pygame, MuJoCo, pytest.
